# UX Psychology

A practical reference package for applying psychology, cognitive science, behavioral science, and human-computer interaction principles to UX design.

## Included

### References
- `principles.md` — foundational UX psychology concepts and when to use them
- `cognitive-load.md` — intrinsic, extraneous, and germane load; chunking and progressive disclosure
- `attention-memory.md` — attention, recognition, recall, memory limits, Von Restorff, and serial position
- `decision-making.md` — choice architecture, Hick's Law, defaults, uncertainty, and decision friction
- `empathy.md` — empathy, mental models, emotion, trust, and user context
- `creativity.md` — divergent/convergent thinking and psychological conditions for creative UX
- `ethical-behavioral-design.md` — ethical persuasion and safeguards against dark patterns

### Checklist
- `checklists/psychology-review.md` — practical review checklist for a UX flow

## Suggested use

Use the package during:
1. Discovery and UX research
2. Information architecture
3. Wireframing
4. Interaction design
5. Content design
6. Onboarding and activation
7. Forms and checkout
8. Error and feedback design
9. Usability reviews
10. Design-system reviews

## Principle

The purpose of UX psychology is not to manipulate users. It is to make interfaces easier to understand, navigate, learn, and use while preserving informed choice and user autonomy.

By Collins
