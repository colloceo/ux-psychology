# UX Psychology

Use this skill when designing, reviewing, or improving user experiences through principles from cognitive psychology, behavioral science, human-computer interaction, learning science, and ethical behavioral design.

## Core workflow

1. Identify the user's goal, context, motivation, and constraints.
2. Map the task flow and locate moments of attention, choice, memory, learning, uncertainty, and action.
3. Apply only the psychological principles relevant to the problem.
4. Reduce unnecessary cognitive effort without removing useful information or user control.
5. Prefer recognition over recall, clear signifiers, visible system status, meaningful feedback, and consistent mental models.
6. Check attention hierarchy, grouping, sequencing, defaults, choice architecture, and error recovery.
7. Evaluate trust, emotion, accessibility, and comprehension.
8. Run the ethical-design review before recommending persuasive mechanisms.
9. Validate important assumptions with usability testing, analytics, experiments, or user research where appropriate.

## Output expectations

When reviewing a UX:
- State the observed problem.
- Explain the relevant psychological mechanism.
- Describe the likely user consequence.
- Recommend a concrete design change.
- Distinguish evidence-based reasoning from assumptions.
- Consider accessibility and different user abilities.
- Avoid manipulative or deceptive recommendations.

## Ethical boundary

Persuasion should support informed user goals. Do not recommend deception, coercion, hidden costs, obstructive cancellation, misleading urgency, disguised advertising, shame, or exploiting known vulnerabilities.
