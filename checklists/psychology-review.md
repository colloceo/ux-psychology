# UX Psychology Review Checklist

## Mental models
- [ ] Does the interface match familiar expectations?
- [ ] Are unfamiliar interactions explained?
- [ ] Is terminology consistent?

## Cognitive load
- [ ] Is unnecessary complexity removed?
- [ ] Are related items grouped?
- [ ] Is information revealed progressively where appropriate?
- [ ] Are users asked to remember information the UI could show?

## Attention and memory
- [ ] Is there a clear visual hierarchy?
- [ ] Is the primary action obvious?
- [ ] Are important elements distinguishable without making everything prominent?
- [ ] Is essential information reinforced at useful points?

## Recognition and recall
- [ ] Are options visible?
- [ ] Are examples or autocomplete available where useful?
- [ ] Are labels persistent and clear?
- [ ] Is user context preserved?

## Decision-making
- [ ] Is the number of simultaneous choices manageable?
- [ ] Are options grouped meaningfully?
- [ ] Are important differences visible?
- [ ] Are defaults transparent and easy to change?
- [ ] Are costs and consequences clear?

## Interaction
- [ ] Are targets appropriately sized?
- [ ] Are controls clearly signified?
- [ ] Does every important action produce understandable feedback?
- [ ] Can users recover from errors?

## Gestalt and hierarchy
- [ ] Does proximity communicate relationships?
- [ ] Does similarity communicate categories?
- [ ] Is figure-ground separation clear?
- [ ] Is visual grouping doing useful information work?

## Emotion and trust
- [ ] Does the flow create confidence rather than unnecessary anxiety?
- [ ] Are errors respectful and actionable?
- [ ] Are policies and consequences understandable?
- [ ] Does the interface behave predictably?

## Empathy
- [ ] Have user context and constraints been considered?
- [ ] Does the design work for first-time users?
- [ ] Does it account for interrupted or repeated use?
- [ ] Does it preserve user dignity and control?

## Ethical behavioral design
- [ ] Are important consequences disclosed before commitment?
- [ ] Is declining reasonably easy?
- [ ] Are cancellation and reversal paths understandable?
- [ ] Is urgency genuine?
- [ ] Is scarcity genuine?
- [ ] Are defaults non-deceptive?
- [ ] Are users free from shame, coercion, or unnecessary pressure?
- [ ] Would the design remain defensible if the mechanism were fully explained to users?
