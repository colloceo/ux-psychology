# Attention and Memory

## Attention

Attention is selective. Users rarely process every element of a screen with equal depth.

Design for:
- clear hierarchy
- one dominant primary action
- meaningful grouping
- readable typography
- appropriate whitespace
- restrained motion

### Attentional competition

When many elements compete for attention, the user's ability to identify the intended action decreases.

Avoid:
- excessive badges
- multiple competing CTAs
- constant animation
- decorative elements that resemble controls

## Recognition and recall

Recognition is generally easier than recalling information without cues.

Prefer:
- visible options
- autocomplete
- examples
- recent selections
- remembered preferences
- contextual labels

## Von Restorff Effect

Distinctive elements can attract attention and improve memory.

Use distinction for genuine importance, not arbitrary promotion.

## Serial Position Effect

Items at the beginning and end of a sequence can receive stronger recall.

Applications:
- important navigation placement
- structured menus
- reinforcing essential information in confirmation screens

## Externalizing memory

Interfaces can act as external memory:
- progress indicators
- saved drafts
- order summaries
- breadcrumbs
- history
- persistent labels

## Attention review

Ask:
1. What should users notice first?
2. What should they understand second?
3. What can safely be ignored?
4. Are secondary elements stealing attention from the primary task?
5. Does motion communicate something or merely attract attention?
